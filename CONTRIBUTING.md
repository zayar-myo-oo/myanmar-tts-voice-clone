# Contributing

Work within the current verified phase. Describe the objective, exact commands,
verification evidence, common errors and completion criteria for every new phase.
Use Python type hints and strict TypeScript when the UI is introduced. Keep engine,
MCP transport, UI and training concerns separate. Run pytest before submitting.

Never commit recordings, model weights, secrets, local environment reports or datasets.
Record upstream revision, license and source for every model. Voice references require
permission. Unsupported vocal directions must return explicit warnings or validation
errors; never imply that signal processing creates a learned emotion.
