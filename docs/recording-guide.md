# ကိုယ်ပိုင်အသံ သွင်းနည်း လမ်းညွှန် (အစအဆုံး)

ဒီလမ်းညွှန်က Nara model ကို **သင့်အသံ** နဲ့ ပြန် train (fine-tune) လုပ်ဖို့ လိုအပ်တာ အားလုံးပါ။
အတိုချုပ်ကို အရင်ဖတ်ပြီး အသေးစိတ်ကို အောက်မှာ ကြည့်ပါ။

---

## အတိုချုပ် (တိုတိုလေး)

1. **တိတ်ဆိတ်တဲ့ အခန်း**: ပန်ကာ၊ AC၊ ရေခဲသေတ္တာ ပိတ်ပါ။ ခုတင်/ကော်ဇော/ခန်းဆီး ရှိတဲ့ အခန်းက ပဲ့တင်သံ နည်းပါတယ်။
2. **မိုက်ခရိုဖုန်း**: USB mic (သို့) ကောင်းတဲ့ ဖုန်း။ ပါးစပ်နဲ့ **၁၅–၂၀ cm**၊ နည်းနည်း ဘေးစောင်းထားပါ။
3. **Format**: **WAV, 48 kHz (သို့) 44.1 kHz, 24-bit (သို့) 16-bit, mono**။ MP3/OGG မသုံးပါနဲ့ (အသံ ပျက်ပါတယ်)။
4. **စာကြောင်း တစ်ကြောင်း = ဖိုင် တစ်ခု**: `r001.wav`, `r002.wav` … (စာသားနဲ့ ID တူရမယ်)။
5. **ဖတ်တဲ့ပုံ**: ပုံမှန် ပြောသလို၊ တစ်သမတ်တည်း အသံ၊ တစ်သမတ်တည်း အမြန်နှုန်း။ စာလုံး တစ်လုံးမှ မလွတ်၊ မပိုစေနဲ့။
6. **ပမာဏ**: အနည်းဆုံး **၃၀ မိနစ်** (≈ ၄၀၀ ကြောင်း)၊ ကောင်းတာက **၁–၂ နာရီ**။
7. **ပို့ရမှာ**: `recordings/<နာမည်>/` ထဲ WAV ဖိုင်တွေ + `metadata.json` (အောက်မှာ ပုံစံ ပါ)။

---

## ၁။ ဘာကြောင့် ဒီလောက် လိုလဲ

Model က သင့်အသံရဲ့ timbre (အသံနေ)၊ အသံထွက်ပုံ၊ စကားဝါနှုန်းကို ဥပမာတွေကနေ သင်ယူပါတယ်။

| သွင်းချက် | ရလဒ် (ခန့်မှန်း) |
|---|---|
| ၂–၅ မိနစ် (ယခု ~၂.၄ မိနစ်) | Train လို့ မရပါ — test အတွက်ပဲ |
| ၃၀ မိနစ် | သင့်အသံနဲ့ ဆင်လာ၊ အမှားတချို့ ရှိနိုင် |
| ၁–၂ နာရီ | သင့်အသံ ရှင်းရှင်း၊ ဂျစ်သံ နည်း |
| ၃–၅ နာရီ | အကောင်းဆုံး၊ စကားလုံး မျိုးစုံ မှန်ကန် |

ပမာဏထက် **အရည်အသွေး** က ပိုအရေးကြီးပါတယ်။ ဆူညံတဲ့ ၂ နာရီထက် သန့်တဲ့ ၁ နာရီက ပိုကောင်းပါတယ်။

---

## ၂။ ပစ္စည်းနဲ့ setting

**မိုက်ခရိုဖုန်း (အကောင်း → အလယ်)**
- USB condenser/dynamic mic (ဥပမာ အခု သင့်စက်မှာ EMEET mic ရှိပါတယ်)
- Headset mic
- ဖုန်း (Voice Recorder app ကို **WAV / lossless** mode ထားပါ)

**Windows မှာ**
- Settings → System → Sound → Input → mic ကို ရွေးပါ။ **Input volume ~70–80%**။
- Windows ရဲ့ "Audio enhancements" / noise suppression ကို **ပိတ်ပါ** (အသံကို ပြောင်းပစ်လို့ပါ)။
- Record program: **Audacity** (အခမဲ့) ကို အကြံပြုပါတယ်။ Project rate 48000 Hz၊ mono၊ Export → WAV (Signed 24-bit PCM)။

**အသံ ကျယ်အား**
- အကျယ်ဆုံး နေရာမှာ **-6 dB မှ -3 dB** ဝန်းကျင် ရောက်ရမယ်။ **0 dB ထိရင် (clipping) မရပါ**။
- အရမ်း တိုးလည်း မကောင်းပါ (-20 dB အောက်)။

**အခန်း**
- လက်ခုပ် တစ်ချက် တီးကြည့်ပါ။ ပဲ့တင်သံ ကြားရရင် ခန်းဆီး/စောင် ထပ်ချိတ်ပါ။ ဗီရိုထဲ အဝတ်တွေကြားက ဖတ်တာလည်း ကောင်းပါတယ်။
- ဖုန်း silent၊ အပြင်က ကား/ခွေး/ဆောက်လုပ်ရေး အသံ နည်းတဲ့ အချိန် (ည) ရွေးပါ။

---

## ၃။ ဖတ်ပုံ (အရေးအကြီးဆုံး)

- **တစ်သမတ်တည်း**: အသံ၊ မိုက်ခရိုဖုန်းနဲ့ အကွာအဝေး၊ အမြန်နှုန်း — session အားလုံးမှာ တူအောင် ထားပါ။
- **စာသားအတိုင်း အတိအကျ**: စာလုံး မကျော်၊ မထပ်၊ မပြောင်းပါနဲ့။ မှားရင် **ဖိုင်တစ်ခုလုံး ပြန်ဖတ်** ပါ။
- **အစ/အဆုံး**: ဖတ်ခြင်း မစခင် **၀.၅ စက္ကန့်** တိတ်ပါ၊ ဖတ်ပြီးလည်း **၀.၅ စက္ကန့်** တိတ်ပါ။
- **ပါးစပ်သံ**: ရေ မကြာခဏ သောက်ပါ (ပါးစပ်ခြောက်ရင် "တောက်" သံ ထွက်)။ ထမင်းစားပြီးချင်း မဖတ်ပါနဲ့။
- **အသက်ရှူ**: စာကြောင်းကြားမှာ ရှူပါ။ ကြီးကြီးကျယ်ကျယ် ရှူသံ ဝင်ရင် ဖြတ်ပါ။
- **ပင်ပန်းရင် နားပါ**: တစ်ကြိမ်ကို **၂၀–၃၀ မိနစ်** ဖတ်ပြီး ၁၀ မိနစ် နားပါ။ အသံ ပြောင်းလာရင် နောက်နေ့ ဆက်ပါ။
- **ဂဏန်း / English**: စာထဲမှာ ဂဏန်း မရေးပါနဲ့ (စာလုံးနဲ့ ရေး)။ English ပါရင် ဖတ်တဲ့အတိုင်း မြန်မာလို ရေးပါ။

---

## ၄။ စာတို vs စာရှည် — ဘယ်လို သွင်းမလဲ

**နည်း A — စာကြောင်း တစ်ကြောင်းချင်း (အကြံပြု)**
- `docs/recording-script.md` ထဲက `rNNN` စာကြောင်းတွေကို တစ်ကြောင်း = ဖိုင်တစ်ခု သွင်းပါ။
- စာသားနဲ့ အသံ ကိုက်ညီမှု အတိအကျ ဖြစ်လို့ train ရ အလွယ်ဆုံး၊ ရလဒ် အကောင်းဆုံးပါ။

**နည်း B — စာရှည် (စာပိုဒ်/ဇာတ်လမ်း တစ်ပုဒ်လုံး)**
- စာသား ဖိုင် (`.txt`, UTF-8) နဲ့ အသံ ဖိုင် (`.wav`) **နာမည်တူ** ထားပါ (ဥပမာ `story01.txt` + `story01.wav`)။
- ဝါကျ တစ်ခုပြီးတိုင်း **စက္ကန့် ၁ ခန့်** ရပ်ပါ — ကျွန်တော်တို့က ရပ်တဲ့နေရာကနေ ဖြတ်ပြီး စာကြောင်းနဲ့ တွဲပါမယ်။
- ဖတ်တာက စာသားအတိုင်း **၁၀၀%** ဖြစ်ရမယ်။ ဖြတ်တွဲပြီးရင် ကျွန်တော် စစ်ပြီး မကိုက်တဲ့ အပိုင်းတွေကို ဖယ်ပါမယ်။
- ကိုယ်တိုင် ရေးထားတဲ့ စာ (video script) သုံးရင် အကောင်းဆုံး — သင့်ရဲ့ video ပုံစံနဲ့ တူတဲ့ အသံ ရပါမယ်။

**နည်း C — လွတ်လွတ်လပ်လပ် ပြော (script မလို)**
- အဆင်ပြေသလို ပြောပါ (ဝါကျ ၁–၂ ကြောင်း၊ ၃–၁၅ စက္ကန့် တစ်ဖိုင်)။ ဖိုင်နာမည် ကြိုက်သလို ပေးပါ (ဥပမာ `free001.wav`)။
- ကျွန်တော်တို့ ASR (အသံ→စာ) က စာသား **draft** ကို `free001.draft.txt` အဖြစ် ထုတ်ပေးပါမယ်။
- သင် draft ကို ဖတ်ပြီး မှားတာ ပြင်၊ ပြီးရင် `free001.txt` လို့ နာမည်ပြောင်းပါ။ `.txt` ဖြစ်မှ training မှာ သုံးပါတယ်။

နှစ်မျိုး (သုံးမျိုး) ရောသွင်းလို့ ရပါတယ်။

**ASR နဲ့ စစ်ခြင်း** (script ဖတ်ထားရင်လည်း): ဖတ်ထားတဲ့ စာနဲ့ script ကိုက်မကိုက် အလိုအလျောက် စစ်ပေးပါတယ်။

```bash
.venv-f5/Scripts/mvs-asr.exe recordings/zayar
```

ရလဒ်ကို `recordings/zayar/transcript_review.md` မှာ ကြည့်ပါ: **ok** = ကိုက်တယ်၊ **check** = မှားဖတ်ထားနိုင် (ပြန်နားထောင်ပြီး ပြန်သွင်း/စာပြင်)၊ **draft** = လွတ်လပ်စွာ ပြောထားတာ (draft စာကို ပြင်ပြီး `.txt` ပြောင်း)။

## ၅။ ဘာစာတွေ ဖတ်ရမလဲ (ပမာဏ ခွဲဝေ)

| အပိုင်း | ပမာဏ | ရည်ရွယ်ချက် |
|---|---|---|
| ပုံမှန် စာကြောင်း (`r001`–) | ၆၀% | အခြေခံ အသံ |
| မေးခွန်း (…လား၊ …လဲ) | ၁၀% | မေးသံ |
| ဂဏန်း၊ ရက်စွဲ၊ အချိန် (စာလုံးနဲ့) | ၁၀% | နံပါတ် ဖတ်ပုံ |
| ပါဠိ/ဘုရား/သမိုင်း စကားလုံး | ၁၀% | ခက်တဲ့ စကားလုံး (ကမ္ဘာ၊ ဘုရားဖူးစခန်း …) |
| ကိုယ့် video script ပုံစံ | ၁၀% | ကိုယ့်ပုံစံ |

**ခံစားချက် (ရွေးချယ်ခွင့်၊ Phase 8 အတွက်)** — တကယ့် emotion လိုချင်ရင် **တူညီတဲ့ စာကြောင်း ၅၀ ကို** ခံစားချက် တစ်ခုချင်းနဲ့ ဖတ်ပါ:
`neutral / happy / sad / excited / calm / angry / suspense / whisper / shout`
ဖိုင်နာမည်: `e_happy_001.wav` စသဖြင့်။ ခံစားချက် တစ်ခုကို **၁၀–၂၀ မိနစ်** ရှိရင် ပိုကောင်းပါတယ်။
Whisper/shout ကို တကယ် တိုးတိုး/အော် ပြောရပါမယ် (mic နဲ့ အကွာအဝေး shout မှာ ပိုဝေးပါ၊ clipping မဖြစ်စေနဲ့)။

```json
{
  "speaker_id": "zayar",
  "display_name": "Zayar — Narrator",
  "gender": "male",
  "age_range": "20-30",
  "style": "calm narrator",
  "microphone": "EMEET USB mic",
  "sample_rate": 48000,
  "consent": "I own this voice and allow it to train my personal model.",
  "commercial_use_allowed": false,
  "recorded_dates": ["2026-11-18"]
}
```

## ၇။ မပို့ခင် ကိုယ်တိုင် စစ်ရန် (checklist)

- [ ] ဖိုင်တိုင်း WAV, mono, 44.1/48 kHz
- [ ] ဖိုင်နာမည် = စာကြောင်း ID
- [ ] Clipping မရှိ (Audacity မှာ အနီရောင် မပေါ်)
- [ ] နောက်ခံ ဆူညံသံ မရှိ (တိတ်တဲ့နေရာကို headphone နဲ့ နားထောင်)
- [ ] စာလုံး မလွတ်၊ မထပ်
- [ ] အစ/အဆုံး တိတ်ချိန် ၀.၅ စက္ကန့်
- [ ] Session တိုင်း mic အကွာအဝေး၊ volume တူ

## ၈။ ပို့ပြီးရင် ကျွန်တော် ဘာလုပ်မလဲ

1. **အလိုအလျောက် စစ်**: format၊ clipping၊ ဆူညံသံ (SNR)၊ အသံ အရှည်၊ တိတ်ချိန်။
2. **စာသားနဲ့ တွဲ**: ID အလိုက်၊ (နည်း B ဆို) ရပ်တဲ့နေရာကနေ ဖြတ်ပြီး တွဲ။
3. **Train/validation ခွဲ**: ၉၅% / ၅%။
4. **Fine-tune**: Nara (Kokoro-82M) ကို RTX 3070 Ti 8 GB ပေါ်မှာ train (step အနည်းငယ်နဲ့ အရင် memory စစ်)။
5. **နှိုင်းယှဉ်**: training မှာ မပါတဲ့ စာကြောင်းတွေနဲ့ အသံထုတ်ပြီး သင့်ဆီ ပို့ — rating ပေးရန်။
6. **Voice profile** အဖြစ် app ထဲ ထည့် (`config/voice_presets.json`)။

> မှတ်ချက်: Nara ကို fine-tune လုပ်တဲ့ training code ကို model publisher က ထုတ်ပေးထားခြင်း ရှိမရှိ
> မစစ်ရသေးပါ (Phase 7 ရဲ့ ပထမ အလုပ်)။ မရှိရင် Kokoro training code ကို ပြင်သုံးရပါမယ်။

| အမှား | ဖြေရှင်းနည်း |
|---|---|
| MP3/OGG/WhatsApp voice note နဲ့ ပို့ | WAV နဲ့ ပြန်သွင်း |
| ဖုန်းရဲ့ noise reduction ဖွင့်ထား | ပိတ်ပြီး ပြန်သွင်း (အသံ စက်ရုပ်ဆန်သွားလို့) |
| နေ့တိုင်း mic နေရာ ပြောင်း | အမှတ်အသား လုပ်ထားပါ |
| စာနဲ့ မတူအောင် ဖတ် | ဖိုင် ပြန်သွင်း (သို့) စာသားကို ပြောတဲ့အတိုင်း ပြင် |

| တစ်ကြိမ်တည်း ၂ နာရီ ဖတ် | ၂၀–၃၀ မိနစ် ခွဲဖတ်ပါ |
