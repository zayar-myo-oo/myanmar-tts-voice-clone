# Desktop audit and usability update

## Verified in this review

- Python: 78 tests passed in .venv-nara.
- Rust: real Python worker synthesis round-trip passed (1 test).
- Frontend: 11 tests passed, including draft restore and undo-clear.
- TypeScript/Vite production frontend build passed.
- Updated UI observed in the running native Tauri dev window.

## Implemented usability improvements

Guided three-step studio header, clearer Burmese labels, larger editor, local draft
auto-save, undo after clear/sample replacement, reset of all delivery settings,
disabled editing while generating, cancellation-error display, clearer export/result
area, completed-result voice label preserved independently of the current selection,
improved contrast/focus and reduced-motion styling. Personal voices no longer infer
gender from absence of a male label. Existing Nara/clone adapters and presets unchanged.

## Remaining work from the original brief

1. Standalone installation: worker.rs searches for a repository and .venv-nara;
   Python engine, FFmpeg, model setup and app-data paths need release packaging.
   No release bundle found; clean-machine Windows/macOS testing remains.
2. Persistence: UI history is React state; service jobs are an in-memory dictionary.
   SQLite-backed history/project recovery and durable output indexing are missing.
   Local draft storage added here does not implement persistent generation history.
3. Script editing: current segment table/JSON renderer exists; graphical timeline,
   drag reorder and individual-segment preview/regeneration workflow remain.
4. Direction presets: list_presets currently returns an empty list. Renderer records
   preset names but does not apply them. Natural-language AI Voice Direction
   Instructions panel/planner and save/load instruction presets remain.
5. Training: dataset QC, ASR and recording review exist. A validated fine-tuning
   training loop/checkpoint/export path on 8 GB is still not implemented.
6. Expression: speed/pitch/pauses are DSP approximations. Learned emotional delivery,
   whisper and shout remain unverified/unsupported.
7. Release reliability: worker read_line has no timeout; add hung-worker recovery.
   Vocos can download on cache miss; provide explicit model setup/offline checks.
   Review .gitignore for .venv-nara and .venv-f5 before any GitHub publication.
   No .github/workflows found. README test totals are older than this audit.
